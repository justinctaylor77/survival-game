# Super Survival Adventure

A kid-friendly 3-level survival game. Solve addition and subtraction puzzles (numbers 0–20) to gather, build, and stay safe through an island rescue, a ship and a wild wave, a tornado, and an earthquake.

Play it in a browser — including iPad Safari — at:

**https://justinctaylor77.github.io/survival-game/**

On an iPad: open the link in Safari, then tap Share → Add to Home Screen for the app icon. Best in portrait, works in landscape too.
