# Super Survival Adventure

A kid-friendly 3-level survival game with addition and subtraction puzzles (numbers 0–20). Play it in a browser — including iPad Safari — at:

**https://justinctaylor77.github.io/survival-game/**

On an iPad: open the link in Safari, then tap Share → Add to Home Screen to get the app icon on the home screen. Best in portrait. No app store install needed.
